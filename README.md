# Applied Machine Learning on AWS — Notebooks

Educational Jupyter notebooks covering Python foundations, tabular classification, and an AWS-oriented MNIST linear learner workflow.

[Português](#português)

## Highlights

- Python reference notebook
- Classification experiments with the Vertebral Column dataset
- MNIST linear-learner workflow
- Notebook-first material for applied machine-learning study

## Getting started

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install jupyter
.\.venv\Scripts\python.exe -m jupyter lab
```

Review the repository files before running commands that access external services or download models and datasets. Never commit credentials or personal data.
